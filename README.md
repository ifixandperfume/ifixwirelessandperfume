# iFix Wireless & Perfume — Website

A colorful, responsive, multi-page static website for:

**iFix Wireless & Perfume**  
4235 W Third Street  
Dayton, OH 45417

## Pages

- `index.html` — Home
- `repairs.html` — searchable iPhone repair menu
- `phones.html` — buy / sell / trade
- `consoles.html` — gaming console repair
- `perfume.html` — perfume & jewelry
- `lottery.html` — Ohio Lottery
- `deals.html` — editable deals/specials
- `contact.html` — address, map, phone and hours placeholders

## Important before publishing

1. Open `repairs.js` and replace the template repair prices with your real prices.
2. Open `contact.html` and replace the phone number and store hours.
3. Replace the stock/placeholder images with your own store photos when ready.
4. Update the deals on `deals.html` whenever you have new promotions.
5. The website currently uses Wikimedia Commons images for the demo visuals. Check the individual file license/attribution requirements before keeping any third-party image in the final public website.
6. The Google Maps links point to the store address.

## Easy future upgrade

This is intentionally built as a simple static site so you can launch it cheaply. Later, the site can be upgraded with:
- online appointment/repair request form
- WhatsApp/SMS buttons
- Google Reviews section
- live inventory
- a password-protected dashboard for changing repair prices and deals
- customer-uploaded store photos
- domain + professional email
- SEO pages for each repair model
